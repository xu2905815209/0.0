精选代表题 · 周期函数的定积分

周期函数乘 x：不拆成 n 段，也能算完整积分

设数列由下式定义，求 an 的表达式。其中 n=1,2,… 为正整数。

an= ∫0nπ x|sinx|dx

这里的上限是 nπ；绝对值只包住 sin x，不包 x。

这道题的三个核心考点

绝对值三角函数的周期性 定积分的区间对称变换 周期分段与数列求和
🔍 第一次做，先看一个选法提示

你可能会想把积分按 0→π、π→2π …… 一段段拆开。可以，但很费事。观察 0 与 nπ 关于中点对称，再想一想：把 x 换成 nπ−x 后，|sin x| 会不会发生变化？

01 / 考场思路

先看“绝对值”，再看“周期”和“中点对称”

sin x 的最小正周期是 2π；但由于有绝对值，负的半波被翻上来，|sin x| 的最小正周期缩短成 π。

|sin(x+π)| =|−sinx| =|sinx|

而且对于任意正整数 n，还满足：

|sin(nπ−x)| =|sinx|

因为 sin(nπ−x)=(-1)n+1sin x，取绝对值后符号消失。于是 [0,nπ] 的左右两端可以相互配对。

一眼识别：定积分里出现 x·f(x)，且 f(x) 关于积分区间中点对称，就尝试替换 x→a+b−x；成对相加，x 就能消掉。
拖动区间长度，看绝对值的周期重复

每多一个 π，就多一个面积为 2 的“拱形”。

完整周期3 段
绝对值正弦的面积6
原积分 aₙ9π
02 / 核心解法：对称变换

不要直接积分 x，把它变成 nπ−x 再相加

记原来的积分为 an。令 t=nπ−x，那么 x=nπ−t，并且 dx=−dt；当 x=0 时 t=nπ，当 x=nπ 时 t=0，上下限也要交换。

an= ∫0nπ (nπ−t) |sint|dt

变量名只是记号，把 t 换回 x。将它与原式相加：

2an= ∫0nπ [x+(nπ−x)] |sinx|dx
=nπ ∫0nπ |sinx|dx
最有用的一步：x + (nπ−x) = nπ，因此原来麻烦的 x 消失了。这就是为什么遇到对称的积分，换元再相加往往比一段段硬算更快。
03 / 周期面积

为什么每个 π 区间的面积是 2？

先只看第一个周期 [0,π]。这一段 sin x ≥ 0，所以绝对值可以去掉：

∫0π |sinx|dx = ∫0π sinxdx =[−cosx]0π =2

从 0 到 nπ 恰有 n 个完整周期，所以总面积是：

∫0nπ |sinx|dx =2n

代回上一节得到的等式：

2an =nπ×2n ⟹ an=n2π
要会复现的方法，不是背一个答案：
“x 乘对称函数” → 换 x 为区间端点之和减 x → 两式相加 → 利用周期面积。
04 / 第二种解法（有助于迁移）

如果没看出对称性，也能按每段积分列递推

把第 n 段单独取出来。设 x=(n−1)π+t，t 从 0 到 π；这段内的绝对值正弦等于 sin t。

an−an−1 =∫0π [(n−1)π+t] sintdt

其中第一部分的积分是 2(n−1)π，第二部分可以用分部积分：

∫0π tsintdt =[−tcost+sint ]0π=π
an−an−1 =(2n−1)π

第一段贡献 π，第二段贡献 3π，第三段贡献 5π……前 n 个奇数之和等于 n²：

an= π[1+3+⋯+(2n−1)] =n2π
两种方法怎么选？本题优先对称法，短且不容易漏符号；如果题目换成 x²|sin x|，简单相加无法直接消掉 x²，就更可能需要分段、递推或其他方法。
