## 已通过筛选并公开的专题
### K001 — 导数图像与原函数增量
- **代表题**：f′ 图像在 0→1、1→3、3→4 下/上/下，面积 3、4、2，f(0)=1，求 f 的区间最值。
- **考点**：牛顿—莱布尼茨公式、定积分带符号面积、导数与最值。
- 来源是曾经有关两条红色公式的学习困惑，但课程不再命名为学生原始问题。
- 主线：f′ 的正负与带符号面积 → 牛顿—莱布尼茨 → 原函数变化量与极值。
- 对比：拉格朗日中值定理与牛顿—莱布尼茨公式分别解决什么问题。
- 文件：\`content/k001.html\`。交互：三段带符号面积切换 + 自测。

### K002 — 分式函数的 n 阶导数
- **代表题**：y=1/[x(1−x)]，求 y 的 n 阶导数（x≠0,1）。
- **考点**：部分分式分解、幂函数高阶导、复合函数链式法则。
- 主线：部分分式分解、负幂求导、链式法则、阶乘与符号规律。
- 标准母题：1/[x(1−x)] 的 n 阶导。
- 文件：\`content/k002.html\`。交互：切换 1/x 与 1/(1−x) 的阶数 + 两道自测。

### K003 — 有理函数不定积分：先整式除法，再部分分式
- **准确代表题**：求 ∫(2t²/(t²−1)−t)dt，t≠±1。图片中分子是 2t²，**不是 2−t**。
- 用户明确更正后，已修复代表题、catalog.json、正文全部推导、对数答案与互动自测。
- **正确路线**：2t²/(t²−1)=2+2/(t²−1)；再拆 2/(t²−1)=1/(t−1)−1/(t+1)。
- **最终答案**：2t−t²/2+ln|t−1|−ln|t+1|+C，定义域 t≠±1，各连通区间可有不同积分常数。
- **核心考点**：同次数有理分式先整式除法、部分分式分解、对数型不定积分、求导验算。
- 文件：`content/k003.html`；交互：切换代入 t=1 与 t=−1 求 A、B + 两个辨别题。
